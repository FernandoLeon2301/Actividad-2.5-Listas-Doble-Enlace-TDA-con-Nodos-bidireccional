Actividad 2.5: Listas Doble Enlace TDA con Nodos (bidireccional)

integrantes: -Gonzalez Alvarado Alexa Michelle -Leon Gamez Fernando -Camacho Guerra Jacobo

Descripcion: Esta actividad consiste en el diseño, desarrollo e implementación de un Tipo de Dato Abstracto (TDA) Lista Bidireccional (Doblemente Enlazada) utilizando el lenguaje de programación Java. El objetivo principal es construir la estructura de datos desde cero, gestionando manualmente los punteros de memoria (primero, ultimo, siguiente y anterior), y acoplarla a una interfaz gráfica de usuario (GUI) desarrollada con Java Swing.
